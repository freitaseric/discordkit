DiscordKit é uma camada de framework construída sobre o
[discordgo](https://github.com/bwmarrin/discordgo).

Ele mantém o discordgo como camada de transporte e modelo de dados do Discord,
enquanto adiciona ferramentas de aplicação que desenvolvedores normalmente
precisam construir por conta própria: roteamento de interações, builders
tipados, Components V2, formulários, middleware, roteamento de custom IDs,
sincronização de comandos e um ciclo de vida de respostas mais seguro.

## Comece pequeno

Uma aplicação DiscordKit mínima continua parecendo uma aplicação discordgo
normal:

```go
s, err := discordgo.New("Bot " + os.Getenv("DISCORD_TOKEN"))
if err != nil {
    log.Fatal(err)
}

router := discordkit.NewRouter()

router.Command("ping", func(c *discordkit.Context) error {
    return c.ReplyText("Pong!")
})

s.AddHandler(router.Handle)
```

DiscordKit não esconde o Discord nem o discordgo. Seu objetivo é reduzir a
infraestrutura repetitiva necessária em torno das interações.
